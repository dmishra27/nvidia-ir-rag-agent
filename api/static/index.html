What's in this corpus?

This search runs over 5,389 passages from five NVIDIA documents:

  • CUDA C++ Programming Guide
  • CUDA C++ Best Practices Guide
  • CUDA Math API Reference
  • CUDA Runtime API
  • Nsight Systems User Guide

Topics outside these documents — such as NVLink, H100, and TensorRT — are not part of the source set. Queries on those topics will return low-relevance results rather than finding nothing.

This deployment runs BM25 keyword search only — its 512 MB memory limit can't hold dense embeddings and cross-encoder re-ranking at the same time. The full BM25 + dense + re-ranking pipeline is benchmarked on the Evaluation page.
